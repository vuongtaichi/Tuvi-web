# Lá số Tử Vi – bản xem trên web

Trang web lập lá số Tử Vi, xem vận hạn và lời luận từng cung (lời luận tóm tắt bằng lời của dự án, kèm tên sách và số trang).
Bản này **không kèm văn bản sách**.

Mở trang: sau khi bật GitHub Pages, địa chỉ có dạng `https://<tên-tài-khoản>.github.io/<tên-kho>/`.

Cách bật GitHub Pages: vào kho trên GitHub → **Settings** → **Pages** → mục *Build and deployment*, chọn
*Source: Deploy from a branch*, *Branch: main*, thư mục */ (root)* → **Save**. Đợi khoảng một phút rồi mở địa chỉ trên.

Lá số đã lưu nằm trên trình duyệt của từng máy; dùng nút "Xuất file sao lưu" / "Nhập file sao lưu" để chuyển sang máy khác.

Tử vi chỉ để tham khảo.
